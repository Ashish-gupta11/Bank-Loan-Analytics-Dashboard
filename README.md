# Bank Loan Analytics Dashboard | Power BI
## 📊 Project Overview
This project presents an interactive Bank Loan Analytics Dashboard developed using Microsoft Power BI.
The objective of this project is to analyze loan applications, funded amounts, received amounts, loan performance, borrower characteristics, and key financial metrics.
The dashboard helps identify trends and patterns in loan applications and provides insights into good and bad loan performance.
---
## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Excel / CSV

## 📈 Dashboard Analysis
### 1. Monthly Loan Applications
The dashboard analyzes the monthly trend of loan applications and helps identify changes in application volume throughout the year.
### 2. Loan Applications by State
A geographical analysis is used to understand the distribution of loan applications across different states.
### 3. Loan Applications by Term
Loan applications are analyzed based on:
- 36-month term
- 60-month term
### 4. Loan Applications by Home Ownership
The dashboard analyzes applications based on:

## 🔍 Key Insights
Some important observations from the dashboard are:
1. Good loans account for approximately 86% of total loan applications.
2. Bad loans account for approximately 14% of total applications.
3. The total received amount is higher than the total funded amount.
4. Debt Consolidation represents the largest loan application purpose.
5. Rent and Mortgage customers represent the majority of applications based on home ownership.
6. Loan applications show an increasing monthly trend toward the end of the year.
